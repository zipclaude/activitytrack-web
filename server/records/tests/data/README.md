Cases shared by every implementation of the activity model 1.0, copied from the
Android app's repository (activitytrack/activitytrack, branch `feature/activity-1.0`,
`docs/samples/`), where they are maintained; refresh them from there, never edit
them here.

- `activity-states.json`: the displayed state of an activity (ACTIVITY-MODEL.md §2.2-2.4).
- `activity-migration.json`: the data migration DB 21 -> 22 (ACTIVITY-MODEL.md §6),
  with the reference `scripts/activity_migration.py`.
